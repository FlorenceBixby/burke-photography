Privacy

Family Calendar Sync

Who this covers

This policy covers Family Calendar Sync, a private tool Burke Ruder built for his own household. It is not offered to the public; the only accounts connected to it are Burke's own Google accounts.

What it accesses

With the account owner's consent, it reads recent messages in the connected Gmail inboxes and reads and writes events on the owner's Google Calendar.

How data is used

Message text is used for one purpose: finding real-world dates (school events, appointments, deadlines) and adding them to the owner's calendar, sometimes with the owner's other email address invited as a guest. It never sends, deletes, archives, labels or moves email.

Processing

To find those dates, the text of each message is sent to Anthropic's Claude API, which does not train models on API data, through Cloudflare's AI Gateway, which may keep request logs for a limited time for monitoring. The tool itself keeps only short run logs (sender, subject, event titles) for troubleshooting.

Sharing

Data is never sold, shared with advertisers, or used for any purpose other than the one above.

Google API data

Family Calendar Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from the Google Account's third-party connections page. Questions go to the support contact shown on the Google consent screen.
